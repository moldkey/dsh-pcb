<p align="center"><strong>dsh-pcb — PCB 工艺与报价</strong></p>

线宽/孔径/板边能力检查，按尺寸层数估报价。

## 安装

    dsh plugin --profile web add github:moldkey/dsh-pcb

## 工具

- `pcb_dfm`：工艺能力检查
- `pcb_quote`：价格参考

更多工具：https://deepseekbase.com/zh/tools/
